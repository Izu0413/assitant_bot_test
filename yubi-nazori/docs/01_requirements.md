# ゆびなぞり(仮) 要件定義 v1
作成日: 2026-10-14

## 概要(3行以内)
2〜3歳の子どもが、iPadの画面を指でなぞって遊ぶアプリ。
「せん → かたち → めいろ」の順に、クリアするたびに少しずつ難しいステージが開いていく。
指先を動かす練習を、失敗のない遊びとして毎日少しずつ続けられるようにする。

## ターゲットユーザーと課題
- **使う人**: 2〜3歳の自分の子ども(字は読めない)。家庭のiPadだけで使い、App Storeには出さない。
- **見守る人**: 保護者。インストールし、遊ぶ時間を見守る。
- **課題**: 市販のなぞりアプリは、文字が多かったり、広告や課金の導線があったり、難易度が合わなかったりする。この年齢でも1人で遊べ、成長に合わせて自然に難しくなるものがない。
- **変わること**: 子どもは字が読めなくても、遊びながら運筆(線をなぞる力)を練習できる。保護者は広告や課金の心配をせずに渡せる。

## コア機能(優先度順・3つ以内)

### 機能1: 指なぞりステージ(せん・かたち・めいろ)
- ユーザーストーリー: 2〜3歳の子どもとして、スタートの●からゴールの★まで道を指でなぞりたい。なぞったところに色が付くのが楽しいから。
- 受け入れ条件:
  - スタート地点に、大きな●(直径80pt以上)が表示される。
  - ●から指を置いてなぞると、なぞった部分の道に色が付く。
  - 道からはみ出しても失敗やブザーにはならない。はみ出している間は色が進まないだけになる。
  - 指を離しても、それまでに塗れたところは残る。もう一度触ると、塗れたところの先から続けられる。
  - ゴール★まで塗れたらクリアになる。
  - 道の途中を飛ばしてゴールに触っても、クリアにはならない。道を順番に塗っていく必要がある。
  - 「めいろ」には行き止まりの分かれ道がある。行き止まりに入っても失敗にはならず、戻れば正しい道を進める。
  - 画面に子ども向けの文字は出さない。数字も出さない。

### 機能2: クリアで次が開くレベル構成(全15ステージ)
- ユーザーストーリー: 子どもとして、1つクリアしたら次のステージで遊びたい。だんだん難しくなるほうが飽きないから。
- 受け入れ条件:
  - ステージは次の15個で、上から順に難しくなる。

    | ステージ | 種類 | 内容 | 道の太さ(目安) |
    |---|---|---|---|
    | 1〜3 | せん | 横、縦、斜めのまっすぐな線 | とても太い(120pt) |
    | 4〜6 | せん | カーブ、ジグザグ、波線 | 太い(100pt) |
    | 7〜9 | かたち | まる、さんかく、しかく | ふつう(80pt) |
    | 10〜12 | めいろ | 分かれ道が1つ | ふつう(80pt) |
    | 13〜15 | めいろ | 分かれ道が2〜3つ | やや細い(64pt) |

  - ステージ選択画面には、15個のステージが絵(線の形のサムネイル)で並ぶ。
  - まだ開いていないステージには🔒が付いていて、タップしても始まらない。
  - ステージをクリアすると、次のステージの🔒が外れる。
  - クリア済みのステージは、何度でも遊び直せる。
  - どこまで開いたかはiPadに保存される。アプリを終了して開き直しても、開いた状態が続いている。
  - 太さや当たり判定の甘さなどの調整用の数値は、1つのファイルにまとめる。保護者の要望を聞いてすぐ変えられるようにするため。

### 機能3: ごほうび演出とスタンプ
- ユーザーストーリー: 子どもとして、クリアしたら褒めてもらいたい。それが次も遊ぶ理由になるから。
- 受け入れ条件:
  - なぞっている間は、指の位置でキラキラが出て、やさしい音が鳴る。
  - クリアすると、紙吹雪と拍手の音が出て、スタンプ(動物やくだものの絵)が1つもらえる。
  - クリア画面には「もういっかい ↻」「つぎへ ▶」「おうち 🏠」の絵のボタンがあり、どれも直径80pt以上ある。
  - スタンプ帳の画面で、集めたスタンプが一覧で見られる。まだもらっていない枠は空白で表示される。

## 共通ルール(全画面)
- 子どもが読む文字は出さない。大人向けの小さな説明文だけは出してよい。
- 失敗、ゲームオーバー、減点は一切ない。
- ステージを途中でやめるときは、大人が右上の✕を2秒長押しする。普通のタップでは反応しない。
- iPadの横向きだけで動く。ステータスバーは表示しない。

## やらないこと(v1スコープ外)
- ひらがなや数字のなぞり書き(v2の候補)
- 複数の子どもの切り替え(プロフィール機能)
- App Storeでの公開、課金、広告、ネット通信
- 保護者向けの記録やグラフ(何回遊んだか、どれくらいはみ出したか、など)
- iPhone対応、縦向き対応
- ステージを自分で作る機能(エディタ)
- 子どもがアプリから抜けられないようにする仕組み。iPad標準の「アクセスガイド」を使ってもらい、READMEで手順を案内する。
- Apple Pencil専用の操作。指で遊ぶ前提にする(ペンで触っても指と同じように動けば十分)。

## 成功の定義
- 子どもが保護者の手助けなしに、ステージ1〜3をクリアできる。
- 1週間、家庭で遊んでもらい、子どもが自分から「やりたい」と言う日がある。
- 1か月以内に、子どもがステージ10(最初のめいろ)まで進む。進めない場合は、太さや判定の甘さを調整して直せる。

## 技術的な前提・制約
「ふうせんパーン」(BalloonPop)を作ったときの環境と、その時にうまくいった方法をそのまま使う。

- **開発するMac**: MacBook Air、macOS 26.2、Xcode 26.6
- **動かすiPad**: iPad Pro 11インチ(第2世代)、iPadOS 26.4.2(デベロッパモードはオン)
- **確認用のシミュレーター**: iPad (A16) / iOS 26.5(作成済み)
- **言語とUI**:
  - Swift + SwiftUI で作る。対応OSは iOS 17.0 以上。
  - なぞりの描画や判定に SwiftUI と SpriteKit のどちらを使うかは、技術設計で決める。
  - 外部ライブラリは使わない。
- **署名**:
  - 無料のApple ID(Personal Team、Team ID `JC6U88LQ3V`)を使う。
  - Bundle ID は `com.izumi.YubiNazori`(仮)。
  - 7日ごとにMacにつないで入れ直す必要がある。
- **作る場所**:
  - BalloonPop と同じように、Macの `~/Desktop/claude-code/` の下に新しいプロジェクトとして作る。
  - ビルドの中間ファイルは、Desktopの外(iCloud同期の外)に出す。Desktopの中だと署名エラーになるため。
- **素材**:
  - 効果音はクレジット不要の素材(効果音ラボなど)を使う。
  - ダウンロードは1つずつ承認を取ってから行い、出典を CREDITS.md に記録する。
- **テスト**:
  - 「道を順番に塗れたか」「クリアしたか」「次のステージが開いたか」の判定は、自動テスト(Swift Testing)で確認する。
