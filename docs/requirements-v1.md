# わけプリ(仮) 要件定義 v1
作成日: 2026-10-06

## 概要(3行以内)
友達同士でiPhoneで撮ったプリシートを、話しながら自由に切り分けて、近くにいる相手に配るアプリ。
渡した紙片は渡した人の手元から消え、この世に1枚だけの「もらいもの」になる。
受け取った側には、プリンタから印刷されて出てくるような体験を届ける。

## ターゲットユーザーと課題
- ターゲット: 20代〜30代前半の女性。友達グループで集まったときに使う。
- 課題: デジタル写真はグループLINEなどで全員に同じものが配られて終わり。プリクラの「切って分ける」「1枚しかないものをもらう」という、アナログならではの楽しさや特別感がない。
- これがあると: その場で会話しながら「これあげる」「それちょうだい」と分け合う時間が生まれ、もらった1枚に特別な価値が生まれる。

## コア機能(優先度順・3つ以内)

### 機能1: 切って配る
- ユーザーストーリー: グループの一員として、撮ったプリシートを好きなように切って、誰にどれを渡すか選んで配りたい。なぜなら、話しながら分け合う時間そのものが楽しいから。
- 受け入れ条件:
  - シート上を指でなぞると、その直線(角度は自由)でシートが2つ以上の紙片に分かれる
  - 切る操作は何回でも繰り返せ、配る前なら1つ前の状態に戻せる
  - 同じアプリを開いている近くの端末(目安: 同じ部屋の範囲)が、メンバー一覧に表示される
  - 紙片をメンバーのアイコンへドラッグすると割り当てられ、どの紙片が誰宛てか画面上で分かる
  - 「配る」を押すと、割り当てた紙片がそれぞれの相手に届く
  - 送信が完了した紙片は送り手の端末から削除され、アプリのどこからも見られない
  - 送信に失敗した紙片は削除されず、送り手の手元に残る
  - 誰にも割り当てなかった紙片は送り手自身の分になる

### 機能2: 受け取ると印刷されて出てくる
- ユーザーストーリー: 受け取る側として、もらった紙片をプリンタから出てくるように受け取りたい。なぜなら、デジタルでも「モノをもらった」実感が欲しいから。
- 受け入れ条件:
  - 受信すると、画面上部から紙片がゆっくり押し出されるアニメーションが再生される
  - アニメーションに合わせて印刷音と振動が鳴る
  - 演出が終わると、紙片(切った形のまま、余白は透明または白)がiPhoneの写真フォルダに保存される
  - 送り手自身の分も、配り終えたときに同じ演出で写真フォルダに保存される

### 機能3: 撮影してプリシートを作る
- ユーザーストーリー: グループの一員として、みんなでアプリのカメラで数枚撮り、1枚のシートにしたい。なぜなら、プリクラのように「1枚のシートを分ける」状態を作りたいから。
- 受け入れ条件:
  - アプリ内のカメラで、カウントダウン付きで決まった枚数(例: 4枚)を連続撮影できる
  - 撮影後、全カットが1枚のシートに並んで表示される
  - 撮影した写真やシートは写真フォルダに保存されない(配って紙片になってから初めて保存される)

## やらないこと(v1スコープ外)
- 落書き・スタンプ・美肌加工などの装飾
- 曲線や手描きの形での切り取り(v1は直線のみ)
- 離れた人への送信、アカウント登録、サーバーへのデータ保存
- 受け取り側のスクショ・転送の防止(受け取った後は相手の自由)
- 渡した紙片の返却・取り消し
- Android対応、App Store公開

## 成功の定義
- iPhone 3台を使い、撮影→切る→配る→印刷演出→写真フォルダ保存が通しで動く
- 送り手の端末に、配った紙片が残っていないことを確認できる
- 実際に友達グループで試し、「切り分けている時間が楽しかった」と言ってもらえる

## 技術的な前提・制約
- iPhone専用、Swift / SwiftUIで開発
- 端末同士のやり取りは MultipeerConnectivity を使う(iPhone同士のNFC直接通信は一般アプリに開放されていないため)
- 送受信する双方にアプリのインストールが必要
- 写真フォルダへは「追加のみ」の権限で保存する
- ビルドと実機テストには Mac(Xcode)と iPhone 2台以上が必要
- 期限: 来週を目処に、手元の端末で動く試作品を作る。開発者はiOS開発未経験のため、コードはClaudeが書き、ビルドと実機確認は本人が行う
