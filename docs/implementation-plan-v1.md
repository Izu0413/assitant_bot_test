# わけプリ(仮) 実装計画

設計: [technical-design-v1.md](./technical-design-v1.md)

役割: コードはClaudeが書いてGitHubにpush。本人がMacで `git pull` → ビルド → シミュレータ/実機で確認し、結果(エラー文やスクショ)を返す。

## マイルストーン
- **M0**: Xcodeでビルドしたアプリが、シミュレータと自分のiPhoneで起動する
- **M1(切って配る)**: サンプル画像のシートを切り、2台目のiPhoneに紙片を配れる。届いた紙片は送り手から消える(受け手の表示は最低限)
- **M2(印刷演出)**: 受け手側で紙片が印刷されるように出てきて、写真フォルダに保存される。自分の分も同様
- **M3(撮影)**: アプリ内カメラで4枚撮ったシートから、M1・M2の流れが通しで動く
- **最終**: エラー時の表示を整え、友達グループで試す

## 最初の3タスクの詳細

### タスク1: 開発環境の準備(本人)
1. MacのApp Storeで **Xcode** をインストールし、一度起動する。追加コンポーネントの画面が出たら **iOS** にチェックしてインストール。
2. ターミナル(アプリケーション > ユーティリティ > ターミナル)で Homebrew を入れる。コマンドは https://brew.sh のトップにある1行をコピーして実行。
3. 続けて XcodeGen を入れる:
   ```sh
   brew install xcodegen
   ```
4. リポジトリをMacに持ってくる:
   ```sh
   cd ~/Documents
   git clone https://github.com/Izu0413/assitant_bot_test.git
   ```
- 完了確認: `xcodegen --version` でバージョンが表示される。

### タスク2: プロジェクト雛形とホーム画面(Claudeが書く → 本人が確認)
- Claude: `project.yml`、`WakePuriApp.swift`、`AppState.swift`、`HomeView.swift` を作ってpushする。権限の説明文とBonjour設定もこの時点で `project.yml` に入れておく。
- 本人:
  ```sh
  cd ~/Documents/assitant_bot_test
  git pull
  xcodegen generate
  open WakePuri.xcodeproj
  ```
  Xcode上部の実行先で「iPhone 16」などのシミュレータを選び、▶(または ⌘R)で実行。
- 完了確認: ニックネーム入力欄と「撮る」「受け取る」ボタンが表示され、入力したニックネームがアプリを再起動しても残っている。

### タスク3: 実機で起動(本人)
1. Xcode > Settings > Accounts で「+」から自分の Apple ID を追加。
2. 左のファイル一覧で一番上の「WakePuri」→ TARGETS「WakePuri」→ Signing & Capabilities で **Team** に自分の名前(Personal Team)を選ぶ。Bundle Identifier でエラーが出たら末尾に自分の名前などを足して一意にする。
3. iPhoneをケーブルでMacにつなぎ、iPhoneで「このコンピュータを信頼」。
4. iPhoneの 設定 > プライバシーとセキュリティ > **デベロッパモード** をオンにして再起動。
5. Xcodeの実行先で自分のiPhoneを選んで ▶。
   - `xcodegen generate` をやり直すと Team の選択が消えるので、一度選んだら Build Settings タブで「Development Team」を検索し、表示された10桁の英数字を `project.yml` の `DEVELOPMENT_TEAM: ""` の `""` の中に入れておく(Claudeに伝えてもらえれば入れる)。
6. iPhoneで「信頼されていないデベロッパ」と出たら、設定 > 一般 > VPNとデバイス管理 で自分のApple IDを信頼して、もう一度起動。
- 完了確認: iPhoneのホーム画面からアプリが開ける。
- 注意: 無料アカウントでは7日でアプリの期限が切れる。切れたら▶でもう一度入れ直せばよい。
